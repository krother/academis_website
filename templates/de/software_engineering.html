Software Engineering

Seit meinen ersten Programmen in den 1990ern habe ich einiges an Software entstehen sehen. Egal ob Sie in Python oder Java schreiben, ob Sie SQL oder NoSQL verwenden, am Ende läuft alles darauf hinaus, eine gute Abstraktion zu finden und Bedingungen zu schaffen, unter denen leicht wartbarer Code gedeihen kann. Die KI-gestützte Entwicklung ist dabei ein wichtiger Beschleuniger, ändert aber die Spielregeln nicht grundlegend.

Ich stehe als Teilzeit-Senior-Entwickler für Projekte zur Verfügung. Hier sind ein paar Dinge, die mir in vergangenen Projekten besonders viel Freude gemacht haben:

  • Refactoring von Legacy-Code
  • Verbesserung von CI-Pipelines
  • Erstellen von Testumgebungen
  • Requirements Engineering
  • Vibe-gecodete Prototypen verständlich machen

Coaching

Ich kann Ihr Team dabei unterstützen, Junior- und Mid-Level-Entwickler:innen über mehrere Monate hinweg schneller voranzubringen. Geben Sie Ihrem Team ein erfahrenes Ohr, das gemeinsam nach Lösungen für kleine Anlaufschwierigkeiten sucht. Bringen Sie neue Teammitglieder auf Kurs durch eine Kombination aus Code-Reviews, Peer-Coaching und regelmäßigen Trainingseinheiten. Für den Fall, dass Ihre neuen Mitarbeiter:innen mit einer erfahrenen Person sprechen müssen, eine Vollzeitstelle aber zu viel wäre. Inklusive:

  • wöchentliche Trainingstermine
  • wöchentliche Code-Reviews
  • individuelle Coaching-Sitzungen
  • regelmäßige Stimmungschecks
  • Troubleshooting
  • NDA für vertrauliche Arbeiten
