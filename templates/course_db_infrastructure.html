Database Infrastructure

In this course, you learn to work with the most popular SQL and NoSQL databases. You will create instances of each database in Docker, fill them with data and write Python clients for each of them. You learn to know the strengths and weaknesses of each architecture in order to build reliable data infrastructure.

Goals

You will get hands-on experience running Postgres and MongoDB as Docker containers and connecting to them from Python. The course covers schema design, authentication and performance considerations for both relational and document-oriented databases.

The main goal of the course is to enable you to choose and operate the right database technology for your own data infrastructure.

Topics

Part 1: SQL and NoSQL Databases

Postgres
Schemas in MongoDB
Docker deployment
DB authentication mechanisms

Part 2: Working with Data at Scale

Data ingestion
Indexing text and geo data
Analyzing performance
Sharding and replication
