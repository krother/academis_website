Python Unplugged: Collaborative Coding

We practice programming by writing a Python game together. We have: one computer, one keyboard, one clearly defined task. The person typing switches every five minutes. No skipping.

Goals

This collaborative workshop is for people with basic Python knowledge and for experienced programmers alike. By handing the keyboard around, everybody gets to think, explain and write code together, without hiding behind a screen.

We do not have internet and we do not have AI. It's just Python code and us.

How the event works

Participation is free. If you want to attend these events regularly you will be expected to register for a course with Academis.

The event location is barrier-free. We believe that providing a harassment-free environment matters: the Berlin Code of Conduct is mandatory.
